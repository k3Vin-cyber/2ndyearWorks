# Java Data Structures & Basics

A simple Java project demonstrating fundamental data structures and basic algorithmic logic. This repository serves as a reference and practice space for core Java concepts.

## 📌 Features

This project includes demonstrations of the following concepts:

- **Array Manipulation**: Reversing the elements of an array.
- **Stack (LIFO)**: Using `java.util.Stack` to push and pop elements (Last-In-First-Out).
- **Queue (FIFO)**: Using `java.util.Queue` with `LinkedList` to add and poll elements (First-In-First-Out).
- **Basic Algorithms**: Iterating through arrays and using conditional logic to filter even numbers.

## 🚀 Getting Started

### Prerequisites

To compile and run this code, you will need to have Java installed on your machine.
- [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/) (version 8 or higher)

### Running the Code

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/yourusername/java-data-structures-basics.git
   ```
2. Navigate to the project directory:
   ```bash
   cd java-data-structures-basics
   ```
3. Compile the Java file:
   ```bash
   javac DataStructureDemos.java
   ```
4. Run the compiled Java class:
   ```bash
   java DataStructureDemos
   ```
