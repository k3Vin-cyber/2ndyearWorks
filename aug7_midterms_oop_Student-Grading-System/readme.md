# BSIT Student Grading System 🎓

A Java-based console application designed to calculate and display student grades across multiple grading periods (Prelim, Midterm, and Final). This project demonstrates the practical application of 1-dimensional and 2-dimensional arrays in Object-Oriented Programming (OOP).

## 🚀 Features
*   **Data Storage:** Utilizes 1D arrays for student names and 2D arrays for their corresponding grades.
*   **Dynamic Calculation:** Automatically calculates the final average for each student using nested loop iteration.
*   **Professional Formatting:** Generates a clean, aligned, and readable terminal report using `System.out.printf()`.

## 📁 Project Structure
*   `School.java` - The main driver class that instantiates the system and executes the program.
*   `StudentGrades.java` - Contains the data arrays (names and grades) and the core logic for calculating and displaying the grade report.

## 🛠️ How to Run
1. Open your terminal or command prompt.
2. Navigate to the project directory (`aug7_midterms_oop_Student-Grading-System`).
3. Compile the Java files:
   ```bash
   javac *.java
   ```
4. Execute the main class:
   ```bash
   java School
   ```
