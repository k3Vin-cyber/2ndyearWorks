# 📸 Crazy Web Photo Booth

Welcome to the Crazy Web Photo Booth project for my second-year Information Technology coursework at Interface Computer College. This workspace serves as an organized archive of my web development exercises, focusing on front-end programming concepts, multimedia integration, and interactive application design.

## 🗂️ Project Directory

This folder contains the following completed project file:
* **`index.html`** — An interactive, browser-based photo booth application featuring real-time webcam access, dynamic CSS theming (Classic Cream, Cyberpunk, Darkroom), an automated 3-shot capture sequence, and a virtual mechanical dispensing animation.

## 💻 Tech Stack & Tools

The project within this directory was developed utilizing the following technologies:
* **Languages:** HTML5, CSS3, Vanilla JavaScript
* **IDEs & Text Editors:** VS Code
* **APIs:** MediaDevices API (`getUserMedia`) for camera access, and the HTML5 Canvas API for photo composite rendering and PNG downloading.
