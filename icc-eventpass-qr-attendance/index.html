1. Mobbin.com Swiss Editorial UI/UX Architecture

          
    
            
  • High-Contrast Monochromatic Hierarchy: Inspired by mobbin.com, the UI eliminates visual clutter using pure white/stone surfaces, 1px solid hairline borders, pill-shaped segmented controls, and realistic iOS hardware device frames with a live Dynamic Island status indicator.
    • 
            
  • Authentication Gate (Full Name + 6-Digit Student ID): Students sign in with their Full Name as username and their 6-digit student number as password, persisting their session in localStorage and auto-configuring their QR pass.
    • 
            
  • Poka-Yoke 6-Digit Input Constraint: Every Student ID input enforces inputmode="numeric", maxlength="6", and live regex sanitization (replace(/\D/g, '')) so spaces or letters can never corrupt the database.
    • 
            
  • Two-Step Progressive Disclosure (Hick's Law): Users first select from 5 Programs (BSIT, BSCS, BSCpE, BSBA, BSOA) and then choose their Year & Section (1, 2, 3, 4), dynamically generating codes like BSIT-2.
    • 
          

        


        

          
2. Platform Technologies & Web APIs

          
    
            
  • Camera & Optical QR Decoding (Html5Qrcode): Streams video from the device camera with a 3-second cooldown lock to prevent rapid multi-scan spam.
    • 
            
  • Web Audio API Synthesizer: Generates zero-latency acoustic chimes (880Hz → 1318Hz on valid check-in; 220Hz sawtooth buzz on duplicate/error) without external MP3 files.
    • 
            
  • HTML5 Geolocation API + Haversine Formula: Verifies on-site campus presence within 150 meters, complete with an Indoor Defense Mode toggle for classroom presentations.
