# Midterms OOP & DSA: Multidimensional Arrays 🎓

A Java console application demonstrating the core Object-Oriented Programming (OOP) concepts of Encapsulation, specifically utilizing private data fields accessed via Getter and Setter methods. This project was developed as part of a midterm assignment for the BSIT curriculum at Interface Computer College.

## 🚀 Key Learning Objectives
*   **Encapsulation (Getters & Setters):** Data arrays are declared as `private` within the subclass, requiring data injection from the main execution file via structured setter methods.
*   **Multidimensional Arrays:** Utilizes 1D arrays for student names and 2D arrays to track dynamic grading periods (Prelim, Midterm, and Final).
*   **Separation of Concerns:** Adheres strictly to a two-file architecture, separating execution logic (`School.java`) from data modeling and display formatting (`StudentGrades.java`).

## 📁 Project Structure & Setup
**Required Folder Naming Convention:**
`Midterms_OOP_DSA_multidimensional_arrays_08082026`

**Included Files:**
*   `School.java` - The main driver class containing the raw array data and execution logic.
*   `StudentGrades.java` - The subclass handling data encapsulation (getters/setters) and the final terminal rendering.

## 🛠️ How to Run
1. Open your terminal or command prompt.
2. Navigate to the project directory:
   ```bash
   cd Midterms_OOP_DSA_multidimensional_arrays_08082026
   ```
3. Compile both Java files:
   ```bash
   javac *.java
   ```
4. Execute the main class:
   ```bash
   java School
   ```
