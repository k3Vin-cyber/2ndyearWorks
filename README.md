## ✨ Key Project Highlights

### 🎟️ ICC EventPass QR Attendance (`icc-eventpass-qr-attendance`)
* **QR Code Integration:** Streamlines student and attendee check-ins using scannable QR event passes.
* **Cloud Backend:** Powered by **Firebase** for real-time attendance logging, data persistence, and secure API handling.
* **Responsive Interface:** Designed for fast, reliable use across both desktop check-in stations and mobile devices.

### 📸 Crazy Web Photo Booth (`photobooth`)
* **Live Camera Feed:** Utilizes browser `MediaDevices` / WebRTC APIs to stream webcam video directly onto the canvas.
* **Custom Effects & Strips:** Allows users to snap sequences of photos, apply fun visual filters, and download their photo booth strips.

### 🗂️ UI/UX & Frontend Drills (`four_pillars_one_app` & Coursework)
* **Tactile & Modern UI Design:** Exploration of retro/brutalist aesthetics (solid borders, custom offset drop shadows, monospace typography) alongside modern responsive layouts.
* **Interactive DOM Manipulation:** Dynamic state updates, task tracking logic, and clean vanilla JavaScript event handling without heavy external frameworks.

## 🛠️ Getting Started

To run or test any of these web projects on your local machine:

### 1. Clone this Specific Branch

Run the following command in your terminal to clone the `html-drills` branch directly:

```bash
git clone -b html-drills https://github.com/k3Vin-cyber/2ndyearWorks.git
cd 2ndyearWorks
```

### 2. Launch a Project

Because these projects are built with standard web technologies, you can run most of them directly in your browser:

1. Open the project folder in **VS Code**.
2. Navigate to the desired directory (e.g., `cd photobooth` or `cd icc-eventpass-qr-attendance`).
3. Launch `index.html` using the **Live Server** extension in VS Code (recommended for camera permissions and Firebase module loading).

> **🔒 Note on `icc-eventpass-qr-attendance`:** If cloning for your own testing, ensure your Firebase configuration keys are properly set up and authorized for `localhost` in your Firebase Console.
