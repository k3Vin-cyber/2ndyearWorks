## 🛠️ Getting Started

To run or explore the Python drills on your local machine:

### 1. Prerequisites

* **Python 3.8+** installed on your system ([Download Python](https://www.python.org/downloads/))
* **Git**
* A code editor such as **VS Code**

### 2. Clone this Specific Branch

Run the following command in your terminal to clone the `python-drills` branch directly:

```bash
git clone -b python-drills https://github.com/k3Vin-cyber/2ndyearWorks.git
cd 2ndyearWorks
```

### 3. Run the Python Mini-Demo

Navigate into the project directory and execute the Python script:

```bash
# Navigate to the HCI mini-demo folder
cd july31_prelims_hci_mini-demo-py

# Run the script (replace main.py with the target script filename)
python main.py
```
