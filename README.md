# 🌐 HTML & Web Development Drills

Welcome to the **HTML Drills** branch of the `2ndyearWorks` repository. This section is dedicated to frontend web development exercises, focusing on structural HTML, responsive CSS, and interactive vanilla JavaScript.

---

## 🚀 Featured Drill: Student Task Tracker
*A minimalist, tactile-themed web application designed to help students track their assignments and daily tasks.*

### ✨ Features
* **Tactile UI Design:** Retro/brutalist aesthetic using solid borders, custom drop shadows, and monospace typography.
* **Smooth Animations:** Tasks slide in when added and slide out gracefully when deleted using custom `@keyframes`.
* **Mark as Done:** Easily toggle a visual strikethrough for completed assignments.
* **Keyboard Accessibility:** Hit `Enter` to quickly add a new task without reaching for the mouse.
* **Event Delegation:** Efficient JavaScript event handling for dynamic DOM elements to ensure new tasks are immediately interactive.

### 🛠️ Tech Stack
* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom CSS variables, flexbox, and hover/active states.
* **Vanilla JavaScript:** DOM manipulation and core application logic without external libraries.
