## 🛠️ Getting Started

To explore or run any of the projects and drills on your local machine:

### 1. Prerequisites
* **Java Development Kit (JDK)** (JDK 17 or higher recommended)
* A Java IDE (**VS Code**, **IntelliJ IDEA**, **Eclipse**, or **NetBeans**)
* **Git**

### 2. Clone this Specific Branch
Run the following command in your terminal to clone the `java-drills` branch directly:

```bash
git clone -b java-drills https://github.com/k3Vin-cyber/2ndyearWorks.git
cd 2ndyearWorks
```

### 3. Compile and Run a Drill
Navigate into any project directory and compile the `.java` files:

```bash
# Example: Navigating to a project folder
cd CinemaTicketingSystem

# Compile and run (adjust Main class name depending on the folder)
javac Main.java
java Main
```
